# Анализ прибыльности продаж Sample Superstore

Аналитический проект по оценке выручки, прибыли и влияния скидок на финансовый результат розничных продаж. Анализ выполнен в Google Colab с использованием Python, pandas и SQL.

## Цель проекта

Определить, какие категории и подкатегории формируют прибыль или убыток, а также проверить связь между размером скидки и отрицательной прибылью.

## Данные

В проекте используется датасет **Sample Superstore**:

- 9 994 строки;
- 5 009 уникальных заказов;
- 793 уникальных клиента;
- основные поля анализа: продажи, прибыль, скидка, категория и подкатегория.


## Подтверждённые результаты

| Показатель | Значение |
|---|---:|
| Выручка | 2 297 200,86 |
| Прибыль | 286 397,02 |
| Маржа прибыли | 12,47% |
| Количество заказов | 5 009 |
| Количество клиентов | 793 |

Ключевые наблюдения:

- категория **Furniture** имеет маржу всего **2,49%**;
- наиболее убыточные подкатегории: **Tables** — −17 725,48; **Bookcases** — −3 472,56; **Supplies** — −1 189,10;
- **88,72% валовых убытков по строкам с отрицательной прибылью** приходится на позиции со скидкой **30% и выше**.

Под «валовыми убытками» здесь понимается сумма абсолютных значений `Profit` только по строкам, где `Profit < 0`. Этот показатель нельзя интерпретировать как долю всех заказов или как причинно-следственное доказательство влияния скидок.

## Бизнес-выводы

1. Общая прибыльность бизнеса положительна, но категория Furniture существенно уступает общей марже.
2. Подкатегории Tables и Bookcases требуют отдельной проверки цен, себестоимости, скидочной политики и условий доставки.
3. Высокие скидки тесно связаны с основной массой валовых убытков в отрицательных строках. Перед изменением политики скидок стоит дополнительно проверить результат по регионам, сегментам клиентов и подкатегориям.
4. Подкатегория Supplies также убыточна, хотя относится не к Furniture; её следует рассматривать отдельно.

## SQL-анализ

Файл [`sql/analysis.sql`](sql/analysis.sql) содержит запросы для:

- проверки количества строк;
- расчёта KPI;
- сравнения категорий;
- поиска убыточных подкатегорий;
- анализа результатов по диапазонам скидки;
- проверки доли валовых убытков, связанной со скидками от 30%.

Запросы используют синтаксис SQLite и предполагают таблицу `sales` с исходными названиями столбцов Sample Superstore. 

## Как воспроизвести проект

### В Google Colab

1. Откройте исходный ноутбук в Colab.
2. Загрузите CSV во временное хранилище Colab или подключите Google Drive.
3. Проверьте путь к CSV в ячейке загрузки данных.
4. Выполните все ячейки сверху вниз: **Среда выполнения → Выполнить всё**.
5. Убедитесь, что итоговые KPI совпадают с таблицей выше.

### Локально

Понадобится Python 3.10 или новее.

```bash
python -m venv .venv
```
